# 면접 준비 자료 만들기

## 목표

저장된 이력서와 채용공고만 근거로, 지원자가 실제 면접 전에 연습할 수 있는 한국어 자료를 만든다.

## 원칙

- 이력서에 없는 회사, 역할, 기술, 수치, 성과를 만들어내지 않는다.
- 필수 요건과 우대 요건을 구분하고, 각 질문이 공고의 어떤 부분을 확인하는지 `focus`에 쓴다.
- 근거를 찾지 못한 경우 `resumeEvidence`에 이력서에서 확인되지 않는다고 분명히 쓴다.
- 답변 개요는 지원자가 자신의 실제 경험을 넣어 완성할 수 있도록 상황, 행동, 결과 순서로 구체화한다.
- `openingPitch`는 약 30~45초 분량의 자기소개 초안으로 작성하되, 확인되지 않은 사실은 포함하지 않는다.
- 예상 질문은 최소 3개, 최대 8개로 작성한다. 기술·직무 질문과 경험·협업 질문을 포함한다.
- 회사에 물어볼 질문은 공고와 회사 설명에 근거해 2~6개로 작성한다.
- 출력은 지정된 JSON 스키마를 만족하는 객체 하나로 제한한다.

## 입력

- `[확정 이력서]`: 지원 기록에 저장한 이력서 구조
- `[확정 채용공고]`: 지원 기록에 저장한 채용공고 구조

## 출력

- `openingPitch`: 면접 시작에 쓸 30~45초 소개글
- `questions`: 예상 질문과 확인 의도, 이력서 근거, 답변 개요
- `questionsToAsk`: 면접 마지막에 지원자가 회사에 물어볼 질문
