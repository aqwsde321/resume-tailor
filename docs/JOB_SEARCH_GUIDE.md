# 이력서 기반 공고 검색

`/jobs`에서 저장된 이력서를 기준으로 공식 API 공고를 모아 적합 근거와 함께 정렬한다. 공고를 선택하면 기존 `/company`와 `/pdf` 맞춤 이력서 흐름으로 연결한다.

## 검색 사이트

| 사이트 | 연결 방식 | 검색 범위 |
| --- | --- | --- |
| 사람인 | 공식 채용 공고 검색 API | 입력한 검색어로 검색. 하루 최대 500회이며 결과에 `Powered by 취업 사람인`을 표시한다. |
| i-ONE JOB | 공식 채용정보 Open API | 검색어 파라미터가 없어 최신 등록순 100건을 조회한 뒤 이력서 적합도로 정렬한다. |

두 사이트 모두 발급된 API 키가 필요하다. 기업회원 전용이거나 개인 프로젝트에서 API 사용 권한을 확인할 수 없는 사이트는 검색 공급자에서 제외했다. 지원하지 않는 사이트를 검색 목록이나 직접 검색 링크로 노출하지 않는다.

사람인에는 검색어만 전달한다. i-ONE JOB에는 키, 페이지, 출력 건수, 정렬 순서만 전달한다. 이력서 원문은 외부 API로 보내지 않고 앱 서버에서 공고 요약과 비교한다.

## API 키 설정

1. `.env.example`을 참고해 프로젝트 루트에 `.env.local`을 만든다.
2. 신청 후 발급된 키를 서버 환경 변수로 설정한다.

```dotenv
SARAMIN_ACCESS_KEY=발급받은_사람인_키
IBK_ONEJOB_ACCESS_KEY=발급받은_i-ONE_JOB_키
```

3. 개발 서버를 다시 시작하고 `/jobs`에서 사이트별 키 설정 상태를 확인한다.

키를 브라우저 코드나 Git에 저장하지 않는다. 사람인 키는 이용 신청 승인 후 앱을 등록해야 발급된다. i-ONE JOB의 API 문서는 채용정보 엔드포인트와 인증키 사용을 안내한다. API 키 발급 조건이 바뀌거나 계정별로 다를 수 있으므로 각 사이트의 최신 신청 화면과 이용 조건을 확인한다.

## 현재 범위와 한계

- 사람인 결과는 검색어로 최대 50건을 가져온다. i-ONE JOB은 최신순 첫 페이지 최대 100건을 가져오며 직무 키워드 요청은 지원하지 않아, 그 결과 안에서 이력서 적합도를 계산한다.
- 적합도는 API가 제공한 제목, 직무 키워드, 경력 등 요약 필드와 이력서를 비교한다. 공고 전체 본문을 분석한 결과가 아니므로 검토용이다.
- 검색 키가 없거나 결과가 비어 있으면 `/company`에서 직접 공고 내용을 입력하거나 URL을 가져올 수 있다.
- 검색 결과를 선택하면 공고 원문을 가져와 `/company` 맞춤 이력서 흐름으로 연결한다.
