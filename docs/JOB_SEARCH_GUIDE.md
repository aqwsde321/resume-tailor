# 이력서 기반 공고 검색

`/jobs`에서 저장된 이력서의 희망 직무와 기술 스택을 기준으로 공고를 검색하고, 결과를 이력서와 비교해 관련 근거를 보여준다. 공고를 선택하면 기존 회사 맞춤 이력서 흐름으로 원문을 가져온다.

## 검색 사이트

| 사이트 | 연결 방식 | 설정 |
| --- | --- | --- |
| 사람인 | 공식 채용 공고 검색 API | 승인받은 `access-key` 필요 |
| 고용24 | 공식 채용정보 API | 발급받은 인증키 필요 |
| 원티드 | 사이트에서 공고를 선택한 뒤 URL 가져오기 | 공식 OpenAPI는 인증 신청과 키 발급이 필요하며, 개인 로컬 앱에서 발급 가능 여부는 원티드 승인에 달려 있음 |
| 점핏 | 사이트에서 공고를 선택한 뒤 URL 가져오기 | 이번 확인에서 공개 검색 API 문서를 찾지 못해 URL 가져오기로 연결 |
| 잡코리아 | 사이트에서 공고를 선택한 뒤 URL 가져오기 | 기존 공고 URL 추출 지원을 사용 |

사람인·고용24 API 검색에는 입력한 검색어만 외부 API로 전달한다. 이력서와 공고의 관련성 비교는 앱 서버에서 수행한다. URL 가져오기는 사용자가 선택한 공고 주소를 서버에 전달해 기존 공고 추출 기능으로 읽는다.

## API 키 설정

1. `.env.example`을 참고해 프로젝트 루트에 `.env.local`을 만든다.
2. 발급받은 키를 서버 환경 변수로 설정한다.

```dotenv
SARAMIN_ACCESS_KEY=발급받은_사람인_키
WORK24_OPEN_API_KEY=발급받은_고용24_키
```

3. 개발 서버를 다시 시작하고 `/jobs`에서 사이트 상태가 `키 설정됨`인지 확인한다.

키를 브라우저 코드나 Git에 저장하지 않는다. 사람인 API는 사용 신청 승인 후 키를 발급받아야 하고, 공식 안내에 일일 최대 500회 호출 제한과 `Powered by 취업 사람인` 출처 표시 의무가 있다. 화면은 사람인 공고에 이 출처를 표시한다. 고용24 공고에는 고용24 제공 자료라는 안내와 원문 링크를 표시한다.

## 현재 범위와 한계

- 검색 결과는 API가 돌려준 공고의 제목, 회사명, 키워드, 경력, 위치 등으로만 비교한다. 전체 공고 본문까지 분석한 결과가 아니므로 적합성 표시는 검토용이다.
- 검색 결과가 비어 있거나 API 키가 없으면 원티드·점핏·잡코리아 등에서 직접 고른 공고 URL을 붙여넣어 기존 URL 가져오기 흐름을 이용할 수 있다.
- 사이트가 페이지 구조나 접근 정책을 바꾸면 URL에서 읽히는 내용이 줄어들 수 있다. 가져온 원문을 확인하고 필요하면 직접 붙여넣는다.
- 원티드 공식 OpenAPI는 인증 키 신청이 필요하다. 점핏은 이번 확인에서 일반 개발자용 공고 검색 API 문서를 찾지 못해 자동 검색 연동은 포함하지 않았다.
