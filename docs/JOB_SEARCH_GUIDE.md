# 이력서 기반 공고 검색

`/jobs`에서 저장된 이력서의 희망 직무와 기술 스택을 기준으로 사람인 공고를 검색하고, 결과를 이력서와 비교해 관련 근거를 보여준다. 공고를 선택하면 기존 회사 맞춤 이력서 흐름으로 원문을 가져온다.

## 검색 사이트

현재 자동 검색은 사람인의 공식 채용 공고 검색 API만 사용한다. 사람인 API 이용 신청과 앱 등록 승인을 받은 뒤 발급된 `access-key`가 필요하다. 기업회원 전용이거나 개인 프로젝트의 API 사용 권한을 확인할 수 없는 사이트는 `/jobs` 검색 공급자에서 제외했다.

검색 요청에는 입력한 검색어만 사람인 API로 전달한다. 이력서와 공고의 관련성 비교는 앱 서버에서 수행한다. 지원하지 않는 사이트는 `/jobs` 검색 목록이나 직접 검색 링크로 노출하지 않는다.

## API 키 설정

1. `.env.example`을 참고해 프로젝트 루트에 `.env.local`을 만든다.
2. 사람인에서 발급받은 키를 서버 환경 변수로 설정한다.

```dotenv
SARAMIN_ACCESS_KEY=발급받은_사람인_키
```

3. 개발 서버를 다시 시작하고 `/jobs`에서 사이트 상태가 `키 설정됨`인지 확인한다.

키를 브라우저 코드나 Git에 저장하지 않는다. 사람인 API는 사용 신청 승인 후 키를 발급받아야 하고, 공식 안내에 일일 최대 500회 호출 제한과 `Powered by 취업 사람인` 출처 표시 의무가 있다. 화면은 사람인 공고에 이 출처를 표시한다.

## 현재 범위와 한계

- 검색 결과는 API가 돌려준 공고의 제목, 회사명, 키워드, 경력, 위치 등으로만 비교한다. 전체 공고 본문까지 분석한 결과가 아니므로 적합성 표시는 검토용이다.
- 사람인 API 키가 없거나 검색 결과가 비어 있으면 자동 목록을 표시하지 않는다. 기존 `/company` 단계의 공고 입력·URL 가져오기 기능은 별도 흐름으로 유지한다.
- 검색 결과를 선택하면 공고 원문을 가져와 `/company` 맞춤 이력서 흐름으로 연결한다.
