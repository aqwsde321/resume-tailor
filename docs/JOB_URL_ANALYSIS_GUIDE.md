# 공고 URL 분석

`/jobs`는 사용자가 직접 입력한 채용공고 링크만 처리한다. 공고 목록을 자동 검색하거나 채용 사이트 API 키를 요구하지 않는다.

## 흐름

1. 저장된 이력서가 있는 상태에서 사용자가 공고 URL을 입력한다.
2. 서버가 링크의 페이지에서 공고 내용을 불러온다.
3. 공고 내용을 회사, 포지션, 주요 업무, 필수·우대 요건, 기술 정보로 구조화한다.
4. 구조화한 직무·기술 정보와 이력서를 비교해 적합 근거를 보여준다.
5. 사용자가 선택하면 URL, 공고 원문, 구조화한 내용을 `/company`의 맞춤 이력서 흐름으로 전달한다.

## 데이터 처리

- 공고 URL은 사용자가 제공한 주소만 요청한다.
- 공고 URL과 페이지 내용은 서버에서 처리한다. 이력서 원문은 채용 사이트로 보내지 않는다.
- 페이지에서 내용을 가져오지 못하면 오류를 알리고, 결과를 만들지 않는다.
- 로그인이나 접근 제한이 필요한 페이지는 읽지 못할 수 있다.
- 이 기능에는 채용 사이트 API 키나 별도 신청 절차가 없다.

## 분석 기준

- 공고의 직무 제목과 기술·요건 정보로 이력서의 희망 직무, 기술 스택, 프로젝트 기술을 비교한다.
- 결과에는 겹치는 기술과 관련 근거를 표시한다.
- 공고 요건에서 이력서에 없는 경험이나 성과를 만들어내지 않는다.
- 분석 결과는 검토용이며, 사용자가 내용을 확인·수정한 후 맞춤 이력서 단계로 넘긴다.
