# 이력서 작업 공간 개편

## 확정한 사용자 흐름

- 내 이력서: 자료 등록 → 추출 문서 검토 → 수정 댓글 일괄 반영 → 변경 수락 → 이력서 확정
- 회사별 이력서: 공고별 작업 생성 → 공고 검토 → 맞춤 초안 → 변경 검토·편집 → 버전 보관 → PDF/Markdown 출력
- 설정: Codex 기본 모델 또는 직접 모델 지정, 생각 깊이, 백업·복원
- 소개글은 선택 사항이며 이력서 편집이나 출력의 선행 조건이 아니다.
- 경력·프로젝트는 최신순을 기본으로 하고 관련 경험은 강조와 분량으로 조정한다.
- 공통 이력서 변경 시 기존 회사별 편집본을 보존하고 새 원본 적용 여부를 선택한다.
- 지원 관리·면접·후속 메일·칸반·달력은 새 주요 메뉴에서 제외하고 기존 자료는 보존한다.

## 보관 정책

`private-data/workspace/`는 Git에서 제외한다. 원본 파일, 추출 문서, 위치 정보, 댓글, 변경 이력, 확정 JSON, 경험 보완 대화와 초안, 회사별 버전을 로컬에 보관한다.

`workspace.json`은 형식 버전과 수정 번호를 가진다. 저장 시 임시 파일을 작성한 후 교체한다. 다른 탭의 오래된 저장은 409로 거절한다. 읽기에 실패한 파일은 초기값으로 덮어쓰지 않는다. 중단으로 `.write-lock`이 남으면 실행 중인 저장 작업이 없는지 확인한 뒤 잠금 폴더를 제거해야 한다.

브라우저에 남아 있는 이전 데이터는 사용자가 가져오기를 선택했을 때만 이전하며 원본 백업도 보관한다. 원본 PDF 등 첨부자료는 파일로 보관하고 문서에서는 식별자로 연결한다.

## 경험 보완

원본 참고: [Resume Tailoring Skill](https://github.com/varunr89/resume-tailoring-skill), [branching-questions.md](https://github.com/varunr89/resume-tailoring-skill/blob/master/branching-questions.md).

답변에 따라 다음 질문을 고르고, 역할·행동·결과를 확인한다. 사용자가 제공하지 않은 성과 수치를 만들지 않는다. 경험이 없다고 답하면 건너뛸 수 있다. 기존 `discover-experience` 흐름을 확장하여 공고 없이도 내 이력서의 부족한 정보를 보완하고, 여러 초안을 모아 승인한 항목만 반영한다. 질문과 답변도 초안의 근거로 보관한다. 승인 전에는 공통 이력서나 회사별 결과를 변경하지 않는다.

## 구현 단위

1. 로컬 저장·버전·댓글·경험 보완 데이터 구조와 저장 API
2. PDF·이미지 OCR·URL·텍스트·Markdown 추출과 원본 보관
3. 공통 검토 편집기, 댓글 일괄 반영, 변경 수락·복원
4. 내 이력서 확정·재편집과 경험 보완
5. 회사별 작업·원본 갱신 선택·맞춤 초안·버전 보관
6. 선택 소개글·PDF/Markdown 출력
7. 메뉴·설정·모델 선택과 기존 데이터 가져오기
8. 통합 검증과 기존 화면 진입 정리

이 문서는 확정한 계획이다. 기능 제공 여부는 각 구현 커밋과 검증 결과로 확인한다.

## 구현 상태

- 세 메뉴와 루트 진입, 공통·회사별 이력서, 모델 ID 직접 지정·기본 모델 선택을 연결했다.
- 추출 문서는 읽기·댓글 모드와 직접 편집 모드를 제공한다. 문장 선택 댓글은 하이라이트로 표시하고, 원본 사각형은 해당 영역만 잘라 OCR로 다시 읽는다.
- 댓글을 일괄 반영하고 개별 제안을 수락·되돌릴 수 있다. 선택 위치가 달라진 댓글은 현재 선택 영역에 다시 연결할 수 있다.
- 공통 이력서를 확정하기 전에 구조화 결과를 확인한다. 학력·자격·연락처·프로젝트 소속·기간을 보존하며 기본 최신순 정렬을 해제할 수 있다.
- 질문별 경험 초안을 모아 새 항목 또는 기존 경력·프로젝트를 선택해 보완한다. 기존 설명은 유지하고 확인한 추가 사실을 덧붙인다.
- 회사별 초안은 원본 근거와 함께 표현별로 선택 적용한다. 공통 원본 갱신은 편집본을 덮어쓰지 않으며, 변경 적용 전 편집본은 버전으로 보관한다.
- 소개글 없이 PDF를 출력하고 Markdown을 내려받을 수 있다. 생성한 PDF는 첨부자료로 보관한다.
- 원본 파일을 포함한 JSON 백업·복원과 이전 브라우저 자료·PDF 가져오기를 제공한다. 이전 자료를 삭제하지 않는다.

## 공통 이력서의 Markdown 편집

- 정리 결과 원문은 Markdown으로 저장한다. `#`는 이름, `##`는 큰 목차, `###`는 회사·프로젝트명이며 직접 편집에서 위계를 바꿀 수 있다. 목록과 굵은 글씨도 읽기 화면에 반영한다.
- 읽기 화면은 Markdown 원문의 위치를 유지해 드래그 댓글과 AI 수정 제안을 연결한다. 기존 일반 텍스트 초안은 댓글·제안 위치를 변환해 가져온다.
- 재정리는 구조화된 이력서 항목만 갱신하고 사용자가 편집한 Markdown은 유지한다. 공통 이력서를 저장하거나 다시 편집해도 목차 위계를 보존한다. 실제 PDF 디자인은 회사별 이력서 완성 이후에 선택한다.

## 내 이력서 화면 상태

- 자료 확인에서는 원본과 추출 내용을 비교하고 직접 고친다. 새 댓글은 이력서 편집 단계에서만 작성하며, 이전 자료에 남은 댓글은 계속 처리할 수 있다.
- 이력서 편집에서 Markdown 댓글 검토, 원본 비교, 수정 되돌리기와 선택형 경험 보완을 제공한다. 보완한 경험은 기존 Markdown을 유지한 채 초안에 추가하며 저장본을 즉시 바꾸지 않는다.
- 저장 후에는 저장된 공통 이력서와 수정·회사별 작업 버튼만 보여준다. 원문 편집이나 경험 보완 패널을 다시 펼치지 않는다. 자료를 교체하면 자료 확인 상태를 별도로 보관한다.

## 범위와 검증 한계

- 파일 20MB, PDF 40페이지, 첨부자료 합계 100MB까지 JSON 백업을 지원한다. 더 큰 자료는 로컬 저장 폴더를 직접 백업한다.
- URL 접근 제한이나 OCR 인식 실패는 원문 검토에서 안내하며, 직접 입력으로 보완한다. 자동 추출이 완전하다고 가정하지 않는다.
- 모델 ID의 사용 가능 여부와 생각 깊이 지원은 실행 시 Codex가 판단한다. 앱은 최신 모델 목록을 별도로 고정하지 않는다.
- 화면 검증은 자동 E2E로 수행했다. 개인 자료를 사용한 실제 AI 응답·OCR 품질 확인과 수동 시각 검증은 별도로 수행하지 않았다.
