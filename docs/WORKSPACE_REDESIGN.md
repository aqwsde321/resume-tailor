# 이력서 작업 공간 개편

## 확정한 사용자 흐름

- 내 이력서: 자료 등록 → 추출 문서 검토 → 수정 댓글 일괄 반영 → 변경 수락 → 이력서 확정
- 회사별 이력서: 공고별 작업 생성 → 공고 검토 → 맞춤 초안 → 변경 검토·편집 → 버전 보관 → PDF/Markdown 출력
- 설정: Codex 기본 모델 또는 직접 모델 지정, 생각 깊이, 백업·복원
- 소개글은 선택 사항이며 이력서 편집이나 출력의 선행 조건이 아니다.
- 경력·프로젝트는 최신순을 기본으로 하고 관련 경험은 강조와 분량으로 조정한다.
- 공통 이력서 변경 시 기존 회사별 편집본을 보존하고 새 원본 적용 여부를 선택한다.
- 지원 관리·면접·후속 메일·칸반·달력은 새 주요 메뉴에서 제외하고 기존 자료는 보존한다.

## 보관 정책

`private-data/workspace/`는 Git에서 제외한다. 원본 파일, 추출 문서, 위치 정보, 댓글, 변경 이력, 확정 JSON, 경험 보완 대화와 초안, 회사별 버전을 로컬에 보관한다.

`workspace.json`은 형식 버전과 수정 번호를 가진다. 저장 시 임시 파일을 작성한 후 교체한다. 다른 탭의 오래된 저장은 409로 거절한다. 읽기에 실패한 파일은 초기값으로 덮어쓰지 않는다. 중단으로 `.write-lock`이 남으면 실행 중인 저장 작업이 없는지 확인한 뒤 잠금 폴더를 제거해야 한다.

브라우저에 남아 있는 이전 데이터는 사용자가 가져오기를 선택했을 때만 이전하며 원본 백업도 보관한다. 원본 PDF 등 첨부자료는 파일로 보관하고 문서에서는 식별자로 연결한다.

## 경험 보완

원본 참고: [Resume Tailoring Skill](https://github.com/varunr89/resume-tailoring-skill), [branching-questions.md](https://github.com/varunr89/resume-tailoring-skill/blob/master/branching-questions.md).

답변에 따라 다음 질문을 고르고, 역할·행동·결과를 확인한다. 사용자가 제공하지 않은 성과 수치를 만들지 않는다. 경험이 없다고 답하면 건너뛸 수 있다. 기존 `discover-experience` 흐름을 확장하여 공고 없이도 내 이력서의 부족한 정보를 보완하고, 여러 초안을 모아 승인한 항목만 반영한다. 질문과 답변도 초안의 근거로 보관한다. 승인 전에는 공통 이력서나 회사별 결과를 변경하지 않는다.

## 구현 단위

1. 로컬 저장·버전·댓글·경험 보완 데이터 구조와 저장 API
2. PDF·이미지 OCR·URL·텍스트·Markdown 추출과 원본 보관
3. 공통 검토 편집기, 댓글 일괄 반영, 변경 수락·복원
4. 내 이력서 확정·재편집과 경험 보완
5. 회사별 작업·원본 갱신 선택·맞춤 초안·버전 보관
6. 선택 소개글·PDF/Markdown 출력
7. 메뉴·설정·모델 선택과 기존 데이터 가져오기
8. 통합 검증과 기존 화면 진입 정리

이 문서는 확정한 계획이다. 기능 제공 여부는 각 구현 커밋과 검증 결과로 확인한다.
